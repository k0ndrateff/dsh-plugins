## 2. P0 — блокеры релиза

### P0-1. `/dsh-*` write-роуты открыты cross-origin и локальным процессам

`createIntegrationRoute` читает JSON любого `content-type` и не проверяет
`Origin`, `Sec-Fetch-Site` или токен:
`packages/integration-host/src/route.ts`.

Через эти роуты пишут:

- GitLab: комментарий, ответ в тред, resolve, approve —
  `packages/gitlab/src/host/surface/http.ts`;
- Jira: transition и assignee — `packages/atlassian/src/host/surface/http.ts`;
- Sentry: resolve/ignore/reopen/assign —
  `packages/sentry/src/host/surface/http.ts`;
- browser: клики, клавиши, навигация, close —
  `packages/browser/src/host/panel/route.ts`;
- `/logout` снимает опубликованные инструменты.

Проверено: `curl` с `Origin: https://evil.example`, `Sec-Fetch-Site:
cross-site` и `Content-Type: text/plain` доходит до обработчика GitLab.
`README.md` при этом утверждает «They never write to a provider» — это неверно
для четырёх плагинов.

**Фикс:** центральный guard в `createIntegrationRoute`: JSON content-type,
проверка `Origin`/`Sec-Fetch-Site`, обязательный клиентский заголовок; для
browser `/input` и `/close` — тот же guard. Локальный процесс с заголовком
по-прежнему может писать; это отдельный долг харнесса, который надо явно
зафиксировать.

### P0-2. `/digest on` не работает: время `HH:MM` вместо `HH:mm:ss`

`timingOf` отдаёт `time: "09:00"`, а установленный `dsh-schedule` требует
`HH:mm:ss`:

```text
LOCAL_CLOCK_TIME = /^(?:[01]\d|2[0-3]):[0-5]\d:[0-5]\d(?:\.\d{1,3})?$/
invalid_rule: weekly.time must use HH:mm:ss…
```

Любой `/digest on` и `rebindAll` падает `ScheduleInputError`. Тест не видит
этого, потому что фейковый `FakeSchedule.create` принимает любой payload.

**Фикс:** `toScheduleTime("HH:MM") → "HH:MM:00"`, канонизация IANA-зоны и
тест на точный payload.

### P0-3. Настройки digest откатываются: `ensure()` кеширует первое чтение

`DigestSettingsStore.ensure()` делает `this.loading ??= this.read()` и навсегда
возвращает первый результат. `save()` обновляет `current`, но не `loading`.
Воспроизведено: после `save({time:"07:00", limit:25})` `get()` отдаёт новые
значения, `ensure()` — старые; `POST /settings` отвечает старыми, карточка
откатывает сохранённое; `limit` и время не применяются до перезапуска.

**Фикс:** `await this.loading; return this.current`, обновление `loading` в
`save()`, сериализация записи и уникальное имя `.tmp` (конкурентные `save()`
уже дают `ENOENT`).

### P0-4. Страница Settings → Plugins → Browser падает

`packages/browser/src/client/index.ts` регистрирует `BrowserSettingsPage` без
`inject`, а страница читает `useBrowserSettings` и действия формы.
`BrowserSettingsForm.inject()` не вызывается нигде. Cast
`as unknown as BrowserSettingsProps` скрыл это от typecheck. При открытии
страницы — TypeError.

**Фикс:** `inject: () => form.inject()`, типизация страницы через фейс,
smoke-тест на монтирование.

## 3. P1 — ломает заявленные функции

### OAuth и MCP-мост

- **Повторный Sync/Re-check рвёт соединение.** `McpBridge.publishTools`
  регистрирует новые инструменты до снятия старых; второй `ensure()` при
  живом клиенте получает duplicate name и уходит в `drop()`. Касается
  Atlassian, Sentry, Figma.
- **«Signed in» без access token.** `AuthorizationFlow.run` коммитит grant,
  даже если token endpoint не вернул `access_token`; `toTokenFields`
  подставляет `undefined`, `jsonSafe` выбрасывает поле, UI пишет успех.
- **Endpoint’ы OAuth принимаются без проверки схемы.** `token_endpoint:
  http://` отправит refresh token открытым текстом; `authorization_endpoint:
  javascript:…` попадёт в `<a href>` карточки настроек.
- **Windows: `cmd /c start` с URL.** `&` в authorize URL трактуется как
  разделитель команд; вход ломается, возможна инъекция.
- **Reflected XSS в OAuth callback.** `oauthError` из query вставляется в HTML
  без экранирования.
- **Issuer не сверяется при переиспользовании клиента.** Поле `Grant.issuer`
  пишется, но не читается.
- **Нет защиты от параллельных `ensure()`.** Старт и ручной Re-check могут
  создать два транспорта и два набора инструментов.

### Atlassian и Sentry

- **`atlassianUserInfo` отдаёт `account_id`, код ищет `accountId`.**
  «Assign to me» никогда не появляется.
- **Комментарии Confluence всегда пустые.** `CallToolResult` передаётся туда,
  где ожидается `{results}` внутри `content`.
- **Correlation-хоп Jira теряет summary/status/assignee.** `asRecord(value)`
  применяется к конверту `CallToolResult`; тест подсовывает голый issue.
- **Пустой JQL/search — ошибка с ложным советом.** «Ничего не найдено» — это
  нормальный ответ, а не ошибка вызывающего.
- **Jira `total`/`isLast` не читаются.** Карточка не говорит «25 of N», хотя
  описание это обещает.
- **`cloudId`/`organization` можно передать в карточку, но панель ходит в
  дефолтный аккаунт.** `PanelTarget` не несёт аккаунт.
- **`tidy` ломает отступы в code fence.**
- **Поиск людей навсегда оставляет «Searching…»** при стирании запроса.
- **Sentry suspect commit приклеен ко всей мульти-issue карточке.**
- **Sentry URL из Markdown не валидируется** (`javascript:` в `href`).
- **В `dsh.client.inject` Atlassian нет `dsh-client-ui-sidebar-right`.**
- **Карточка настроек Atlassian не показывает `siteUrl`.**

### GitLab и Figma

- **Дифф врёт на нескольких хунках.** `@@` выбрасывается, все изменения
  склеиваются в один `DiffHunk`.
- **Строки `--- old`/`+++ new` выпадают** из диффа и из `+N/−M`: удаление
  SQL-комментария `-- old` не видно.
- **Пагинация молча режет discussions/diffs/jobs на 100.**
- **GitLab auth врёт:** на чистой установке красная ошибка «no token stored»;
  при 401 — «Signed in» и «2 tools».
- **Figma не закрывает MCP-мост при выгрузке/перезагрузке.**
- **Figma `fileKey` парсится и выбрасывается:** ссылка на другой файл читает
  текущий открытый.
- **Figma id вложенных инстансов отвергаются** (`I123:456;789:12`).
- **Ветки дают ложные tracker-ключи** (`LODASH-4`, `RELEASE-2026`).
- **Flat-ветка `parseDiscussions` OR-ит resolved** вместо «все разрешимые
  заметки закрыты».
- **`x-total: null` → `total: 0`.**
- **Сообщение об усечённом логе говорит «beginning», хотя оставлен конец.**
- **Сырые enum’ы в UI** (`cannot_be_merged_recheck`, `script_failure`).
- **Figma-счётчики выдают усечённое за полное.**

### Digest, correlation, devkit

- **Конкурентные `save()` теряют правку** (общий tmp, нет очереди).
- **`patchOf` читает блоки до `ensure()`** и затирает сохранённые
  переключатели.
- **Каждый POST вызывает `rebindAll`** и пересоздаёт напоминания всех сессий.
- **`rebindAll` не атомарен**, `bound()` глотает ошибку каталога → дубли.
- **`isTimeZone` шире, чем сервис** (`CET`, `GMT`, `EST5EDT`).
- **Пустая неделя сохраняется и молча становится Mon–Fri.**
- **`/digest days mon tue` даёт только Mon.**
- **Devkit игнорирует `truncated`/`spillPath` и 64 КБ дефолт** — большой
  `biome --reporter=json` не парсится, диагностик ноль.
- **`/checks` может бросить** из-за `workingDirectory.ensure()` вне try.
- **Счётчики падений расходятся** между session log, валидатором и карточкой.

### Browser

- **`browser_run` пропускает `--session`, `--profile`, `close --all`.**
  Ломается изоляция сессий и opt-in реального Chrome-профиля.
- **Утечка WS-соединения при close во время connect.**
- **После `set viewport` панель не перемеряет страницу** — клики по старому
  масштабу.
- **Hover шлёт POST каждые 60 мс с `button: "left"`**; клик на `mousedown`
  лишает возможности выделять текст.
- **Неудачный close помечает браузер закрытым.**
- **Панель в неактивной вкладке продолжает опрос** (`keepMounted` +
  `document.hidden`).
- **Автооткрытие панели на реплее истории.**
- **`streamMaxFps` читается один раз при активации**, executable кешируется
  навсегда.
- **`select` режет значение по пробелам.**
- **Tab заперт в картинке.**
- **Браузер не закрывается при выгрузке плагина/конце разговора.**

### UI, команды, процессы

- **Результат записи применяется к уже переключённой панели.**
- **`/login` врёт об успехе**, `/status` прячет ошибку и URL.
- **Нет отмены зависшего входа.**
- **Нет CI** на typecheck/build/test/lint: только `market.yml`.
- **`bun run test` mcp-oauth включает живой conformance** и создаёт реальные
  OAuth-приложения.
- **Тесты закрепляют фейки:** duplicate register не бросает, schedule не
  валидирует payload, correlation отдаёт голый issue, `total: 42`, один хунк.
- **`dsh-workflow-plugin` не включает browser**, хотя README обещает «every
  bundle»; тест проверяет только зависимости, а не все бандлы репозитория.

## 8. Статус исправлений
